# Tone Comparison: Warm vs Direct Feedback

*Phase 2 (Task Analysis) - For Lab Meeting Discussion*

本文档展示了基于**相同评分标准和 scaffolding level**，使用不同 tone（warm 和 direct）的反馈示例。

## 核心原则

两种 tone 版本都：
- ✅ 使用**完全相同的评分 rubric**（Task Identification + Resource Specificity）
- ✅ 提供**相同 level 的 scaffolding**（模板/建议/反思问题）
- ✅ 包含**相同深度的 guidance 和 examples**
- ❌ 唯一区别是**沟通方式**（鼓励性 vs 简洁性）

## 🔍 Key Differences Between Warm and Direct

| Aspect | Warm 🌟 | Direct 📋 |
|--------|---------|-----------|
| **Greeting** | Enthusiastic, multiple emojis, celebrates effort | Concise, minimal emojis, states status |
| **Language** | "Great job!", "You're on the right track!", "Fantastic!" | "Good", "Clear", "Needs improvement" |
| **Encouragement** | Frequent positive reinforcement, growth mindset | Minimal praise, focus on actions |
| **Explanation** | More detailed explanations of "why" | Concise, bullet-pointed explanations |
| **Tone** | Supportive, empathetic, motivational | Professional, straightforward, efficient |
| **Emoji Usage** | Frequent (🌟💪✨🎯🎉) | Minimal, only for categories (⚠️💡✅) |
| **Word Count** | Generally 20-30% longer | More concise, gets to point faster |
| **Examples** | More context and explanation | Streamlined, essential info only |

## 📊 Rubric Consistency (Same Across Both Tones)

Both versions use identical scoring:
- **Task Identification**: 0 (generic) → 1 (some detail) → 2 (comprehensive)
- **Resource Specificity**: 0 (generic) → 1 (named but no strategy) → 2 (strategic mapping)

Both versions provide same scaffolding level:
- **LOW (0-1)**: Full template + example
- **MEDIUM (2-3)**: Targeted suggestions + template
- **HIGH (4)**: Reflection questions only
