# Knowledge Check 题目对比清单

## 一、一句话总结

**我们网站已有的 8 道题，Shunki 全选了，而且没有额外要加的。**  
Shunki 在 HTML 里还勾了别的题，那些题我们网站**没有**，但按「减 cognitive load」的原则，我们**不建议加**。
